# Page briefs

One short file per page, post type or message, written before its words
([brand voice](../../guidelines/brand-voice.md#before-you-write-the-brief)). A brief is a few lines,
not an essay. Keep it next to the others, name it for the page, and update it when the page's job
changes.

## Template

```md
# <Page name>

Status: draft for the owner | agreed (date)

- **Purpose:** what the page is for, in one sentence.
- **Audience:** who reads it, and what they want from it.
- **Next step:** the one thing we want them to do after reading.
- **At a glance:** what the reader should be able to see or grasp in the first moment.
- **Tone:** how it sounds, from the brand voice tone map.
- **Open questions:** what the owner still has to decide.
```
