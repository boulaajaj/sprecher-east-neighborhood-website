## How it was made

- **Code:** `main` at `e887427` (2026-10-21).
- **Routes come from the code:** every `page.tsx` under `src/app/(frontend)/`, `not-found.tsx`,
  and the CMS pages the seed creates. Production may have extra CMS pages, or header and footer
  links, made in its admin. The owner confirms that nothing extra exists on the live site.
- **Local, not live.** The live site (https://sprechereast.com) can't be reached from the agent's
  sandbox, so the site ran locally. The components are the same code as production; the content is
  the seed data plus the fixtures below, so text and pictures differ from the live site.
- **Server:** a production build (`next build`, `next start`), except the five captures taken on an
  empty database before seeding (the four empty lists and the unseeded home), which used `next dev`.
- **Content:** the demo seed (`src/endpoints/seed/`), then local-only fixtures for elements the seed
  doesn't use: 14 upcoming and 4 more past events (so "Load more" appears), events with and
  without photos, two post categories, one post with no image that holds every rich-text element,
  and a page `/ui-fixture` with the medium hero, every content-block layout, an archive block and a
  form with every form-builder field. None of this content is committed.
- **Pictures:** Playwright with Chromium, full page, at 375 and 1280 px, light and dark (the theme
  set through the site's own `payload-theme` setting, so `data-theme` on `<html>` is set by
  `InitTheme`). Interactive states are clipped to the element that changes. Real Poppins fonts.
- **States that need a server answer** (sending, server error, "Load more" failing, a new build)
  were produced by intercepting the request in the browser, not by breaking the server.
- **A dated snapshot.** The screenshots show `e887427` and are never refreshed in place.

## How to read the element tables

- **ID:** a letter for the group and a number (`N10`). The component set lists the IDs it covers.
- **Concept:** action, navigation, text input, choice, display, feedback, overlay or layout.
- **Current variant:** how the element looks or behaves today, including drift between copies.
- **Data type and Payload field type:** what the element shows or edits, and the Payload field it
  comes from. "—" means static text or no data.
- **Target component · variant:** the one component and variant the element maps to. A component in
  `platform/ui/` is shared; other components live in a module's `ui/` (see the
  [component set](component-set.md)). `{field}` means the variant is chosen by that CMS field.
- **File:** paths from the repo root, with the line where the element starts.

## Not covered, and why

- **Robot check (F18).** Cloudflare Turnstile needs real keys and its script from
  `challenges.cloudflare.com`, which the sandbox can't reach. It's invisible unless Cloudflare asks
  for a click; its error messages are listed under F16.
- **Draft preview and live preview.** Staff-only views reached from `/admin`; they show the same
  components plus Payload's admin bar.
- **The Payload admin (`/admin`).** Out of scope: it keeps Payload's built-in fields, styled with the
  site's tokens. Its field types are still in the [data-type map](data-types.md).
- **The code block's "Copied!" state and hover states.** Text swaps and hover styles, read from the
  code instead of pictured.
- **Video media (M7).** No video in the seed; the element is read from the code.
- **The forum (discourse.sprechereast.org).** Independent of this site.
